# Expense Tracker App (v2.0.0)
**Repository:** https://github.com/JoshClays/NIT3004-IT-Capstone-Project-2-Backup  
**Release:** https://github.com/JoshClays/NIT3004-IT-Capstone-Project-2-Backup/releases/tag/v2.0.0  

A modern Android expense-tracking application developed as part of **NIT3004 – IT Capstone Project 2** at Victoria University. The app helps users manage income, expenses, and budgets with a clean UI, smart automation, and fully offline functionality.

---

## 🚀 Features
- **Transaction Management:** Quick add, edit, delete, category-based sorting, and search.  
- **Smart Budgeting:** Create budgets with automatic category creation and real-time progress tracking.  
- **Analytics Dashboard:** Spending trends, category breakdowns, income vs expense highlights, and export (CSV/PDF).  
- **Modern UI/UX:** Material Design 3, dark/light mode, responsive layout, smooth animations.  
- **Offline-First Storage:** Local SQLite database, privacy-focused, no ads or tracking.

---

## 🔧 v2.0.0 Enhancements

---

## 📲 Installation
1. Download the APK from the **v2.0.0 Release** page.  
2. Install on any Android device running **API 21+ (Android 5.0+)**.  
3. Grant storage permission only if exporting reports.
